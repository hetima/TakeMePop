# TakeMePop

![Screenshot](https://raw.githubusercontent.com/hetima/TakeMePop/main/assets/ss01.jpg)

ドラッグ・アンド・ドロップの中継地点となるフローティングウィンドウを出すWindows専用アプリケーションです。クリップボード履歴や一時的なテキスト編集機能も備わっています。

起動するとタスクバーに常駐します。終了させるにはタスクバーのアイコンを右クリックして終了を選んでください。環境設定を選べば動作をカスタマイズできます。

## インストール

[リリースページ](https://github.com/hetima/TakeMePop/releases)からダウンロードするか[Scoop](https://scoop.sh/)で入れてください

```sh
#インストール
scoop bucket add hetima https://github.com/hetima/scoop-bucket
scoop install hetima/TakeMePop

#起動
TakeMePop

#アップデート
scoop update hetima/TakeMePop
```

このソフトを使用するには .NET 10 Desktop Runtime が必要です。インストールされていない場合 [ここ](https://dotnet.microsoft.com/download/dotnet/10.0) からダウンロードするか winget コマンドでインストールしてください。

```
winget install Microsoft.DotNet.DesktopRuntime.10
```


## ドロップパネル

ファイルやテキストを一時保管する小さなウィンドウ。

- グローバルショートカットで表示。ドラッグ中でも可能
- Ctrl+C 2回押しでコピーしたファイルを持つパネルを表示します。ドラッグ開始する必要すらありません

パネルには直接ドロップすることができます。中身が入れ替わります。
パネルから他の場所へのドラッグ・アンド・ドロップが完了するとパネルは閉じます（エクスプローラーなどドロップ判定が曖昧なアプリケーションに対しては閉じないこともあります）。

パネル左上の丸いボタンを押すことでピンの切り替えができます。ピン留めされると自動では閉じなくなります。通常はひとつのパネルを使い回して動作しますが、ピン留めしておくとそのルールから外れ、複数のパネルを出すことができます。


## テキストエディット

テキストを一時保管、編集する小さなウィンドウ。チャット入力中などに細かな編集がしたい、改行を入れると送信してしまうのではないかという不安を解消できます。

- グローバルショートカットで表示
- Ctrl+C 2回押しでコピーしたテキストを持つパネルを表示します


## クリップボード履歴

直近のクリップボード履歴を4～10個表示する小さなウィンドウ。ショートカットに設定したモデファイキーを押したままトリガーキーを押すことで表示・選択し、モデファイキーを離すとペーストします。ショートカットで表示、クリックで選択（クリップボードにコピーします）という一般的な動作にすることも可能です。


## ドロップガード

これは「クリックしたつもりがドラッグになってしまい隣のフォルダに放り込んでしまった」というようなミスを軽減させる機能です。ドラッグが始まったらごく短い間、マウスポインタのある場所に限りなく透明なウィンドウを出します。このウィンドウがドロップを吸い込み、何もなかったことにします。環境設定でウィンドウの大きさ、何ピクセル移動したら出現させるか、何秒たったら消すかなどを細かく設定できます。
